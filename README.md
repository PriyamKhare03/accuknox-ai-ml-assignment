# AccuKnox AI/ML Assignment

This repository contains the solutions for the **AccuKnox AI/ML Internship Assignment**. The tasks cover API data retrieval, preprocessing and visualization, and CSV data import into SQLite. The repository is structured to demonstrate clean coding practices, reproducibility, and clear documentation.

---

## 📂 Repository Structure



- **Task 1:** Fetch books from Google Books API and store them in a local SQLite database.  
- **Task 2:** Fetch student scores from a JSON dataset, preprocess the data, calculate averages, and visualize it using a bar chart.  
- **Task 3:** Import CSV data (Mall Customers dataset) into a SQLite database.  

---

## 📝 Task Details

### **Task 1: API Data Retrieval and SQLite Storage**
- **Objective:** Fetch book information (title, author, publication year) from the Google Books API and store it in a SQLite database.  
- **Key Steps:**
  1. API request to Google Books API using `requests`.
  2. Extract relevant fields (`title`, `author`, `publishedDate`).
  3. Create SQLite database `book.db` and `books` table.
  4. Insert API data into the table.
- **Python File:** `books_api_sqlite.py`  

---

### **Task 2: Data Preprocessing and Visualization**
- **Objective:** Process student score data and visualize it.
- **Dataset:** `student_scores.json` (simulates API data).  
- **Key Steps:**
  1. Load JSON data into a pandas DataFrame.
  2. Preprocess: convert scores to numeric, remove missing values.
  3. Calculate average score.
  4. Visualize using a bar chart with `matplotlib`.
- **Python File:** `student_scores_processing.py`  

---

### **Task 3: CSV Data Import to SQLite**
- **Objective:** Import CSV data of Mall Customers into SQLite for further analysis.  
- **Dataset:** `Mall_Customers.csv`  
  - **Source:** Publicly available Kaggle dataset.  
  - **Safety:** Safe to include in GitHub; it contains anonymized data and has no copyright issues.  
- **Key Steps:**
  1. Read CSV using `pandas`.
  2. Connect to SQLite database `customer.db`.
  3. Create table `customer` if not exists.
  4. Insert CSV data into the table using `pandas.to_sql()`.
- **Python File:** `csv_to_sqlite.py`
